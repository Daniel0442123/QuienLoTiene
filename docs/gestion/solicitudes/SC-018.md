## 2. Descripción

**Qué dice el plan hoy:** HU-008 muestra el historial de pedidos y deja repetir uno. «Mis pedidos» solo lista lo que el cliente ya confirmó.

**Qué se propone cambiar:** agregar a HU-008 una sección «Mis preguntas» dentro de «Mis pedidos», con las solicitudes abiertas del cliente de las últimas 24 horas y cuántas respuestas tiene cada una. Al tocar una, abre la pantalla de respuestas (`/solicitudes/nueva?solicitud=<id>`, la misma de DEF-011).

**Motivo:** en la prueba en producción del 18/11 se vio que, si el cliente sale de la pantalla de respuestas sin elegir una tienda, no tiene cómo volver a su pregunta. Recargar ya funciona desde `v0.3.1` (DEF-011), pero no hay una lista para encontrarla.

**Alternativas consideradas:**
- Dejarlo como está. Se descarta porque el cliente pierde las respuestas de las tiendas si sale de la pantalla.
- Guardar la última pregunta en el navegador. Se descarta porque no sirve entre el celular y el PC y solo recuerda una.
